# 剧情记忆

剧情记忆是长篇写作的「备忘录」：几十万字之后，审稿、一致性检查、灵感与续写都要靠它判断「之前发生过什么、现在是什么局面」。
它必须**准确、精炼、可追溯**。每次只读到一批新正文，旧的内容要靠你保留下来。

## 一、事件（events）怎么记

- 只记推动剧情的事件：冲突与结果、重要的决定、关系的变化、身份或秘密的揭示、能力或境界的变化、
  重要物品的得失、约定与期限的设立或兑现、人物的登场、退场与死亡。
- 每条一句话，以章节开头，写清「谁 + 做了什么 + 结果」，例如：
  「第2卷第5章：沈默在码头伏击中救下顾秋，自己左臂中刀，两人约定三日后在旧仓库交换账本。」
  章节取「待查正文」中 `### 第X卷第Y章` 的标题。
- 日常描写、环境描写、重复的情绪不记；「上次记录的事件」里已有的不要再记。

## 二、全书状态怎么更新

状态会**整体替换**旧状态：旧状态中仍然成立的内容必须原样保留，只修改被新正文改变的部分。

- **主线进展（mainline）**：串起截至目前的主线，越早的部分越概括（可以按卷或阶段压缩成一两句），
  但关键转折不能丢；新正文改变了主线走向时要体现出来。
- **人物现状（characters）**：每人一句，写当前所在、境界或实力、伤势、关键持有物、眼下的目标、关键关系，
  以及**掌握的重要秘密**（「已知顾秋的真实身份」）——后续检查要靠它判断谁知道什么。
  状态被新正文改变时要更新，不能保留过时的状态；暂时没出场但仍然重要的人物（幕后对手、失踪的亲人）要保留，注明「暂未出场」。
  已经不再重要的路人可以去掉。
- **未解决的冲突与伏笔（threads）**：悬而未决的冲突、留下的谜团、作者明显埋下的伏笔（反复出现的物品、意味深长的话、
  未说明来历的人）、立下的约定与期限。每条注明埋下的章节，如「（第1卷第3章埋下）」；有期限的写明期限。
  已经解决或揭晓的删去，并把结果记进本次的事件。
- **情绪走势（emotion）**：2～3 句，写最近几章的情绪曲线（蓄压、爆发、余波、平台）及对应章节，以及当前的基调与走向，
  例如「第4～6章持续蓄压，第7章码头一战释放；当前处于余波期，基调转为紧张的悬疑」。

## 三、原则

- 只写原文写到的，不推测作者的意图，不评价好坏；人物的谎言、误判或传闻写成「某某声称……」，不要当成事实。
- 新正文与旧状态冲突时，以新正文为准更新（这是剧情推进，不是你的错误）。
- 专有名词以原文与「设定上下文」为准，不要自造简称；同一人物前后用同一个名字。
- 篇幅有限时，优先保留：主线转折、主要人物的状态与知情范围、未兑现的约定与伏笔；其次才是次要人物与细节。
