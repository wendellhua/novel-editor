# 章节摘要

你在为后续章节的检查与写作准备「前情提要」，摘要要**信息密集、客观、可检索**，重点是「下一章需要接着什么」。

1. **长度**：不超过 200 字，一段话，不分点、不换行。
2. **内容**（从高到低，篇幅不够时从后往前舍弃）：
   - 主要事件及结果（谁、在哪里、做了什么、结果如何）；
   - 人物状态与关系的变化，写变化后的状态（「沈默升为三阶」）；
   - 新立下的约定、期限、目标，谁新知道了什么秘密；
   - 首次出现的重要人物、地点、物品、规则；
   - **章末状态**放在最后一句：人物停在哪里、准备做什么、留下什么悬念。
3. **写法**：第三人称、按时间顺序、陈述句，写出明确的时间与地点转换；专有名词保持原文写法；
   不评价、不抒情、不用「本章讲述了」开头；不加原文没有的推测，人物的谎言写成「某某声称……」。
4. 标题注明「片段 i/n」（n 大于 1）时，只概括这一片段，最后一句写这一片段结束时的状态。
