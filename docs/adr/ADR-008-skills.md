# ADR-008：Skills 兼容层——SKILL.md 作为提示词包，内置检查也是技能
- **状态**：已采纳
- **日期**：2026-10-09

## 背景 (Context)
- 用户的要求：
  - 技能采用和 CodeBuddy / SkillHub 一致的 SKILL.md 格式；
  - 可以从 SkillHub 安装，也可以本地导入；
  - 技能只作为提示词使用，不执行代码；
  - 技能安装在本地、在本地使用，不考虑第三方调用的风险（2026-10-09 确认）。
- 官方 CLI 的不足：
  - frontmatter 解析器不支持 YAML 多行写法；
  - 解压时没有大小限制（F9）。
- 通用技能的问题：通用技能（例如「起点写作助手」）的输出格式不固定，无法直接转换成可定位的检查问题。

## 候选选项 (Options)
1. **技能完全接管提示词，包括输出格式**
   - 缺点：输出格式不可控，无法定位和一键修正。
2. **编辑器协议 + 技能规则（分层组装）**
   - 做法：编辑器固定角色、通用规则和输出 Schema，技能只提供领域规则。
   - 优点：任何 SKILL.md 都能接入，输出始终结构化。
   - 缺点：技能里关于自身输出格式的要求会被编辑器协议覆盖。
3. **自定义技能格式**
   - 缺点：与现有生态不互通。

## 决定 (Decision)
采用选项 2，细节见 ARCHITECTURE §7.4.1、§7.5。

**内置技能**：编辑器内置以下 6 个技能，它们和用户安装的技能走同一条执行路径：

| 技能 | 用途 |
|---|---|
| `typo-check` | 错别字检查 |
| `editorial-review` | 编辑审稿 |
| `setting-consistency` | 设定一致性 |
| `character-consistency` | 角色一致性 |
| `bible-extract` | 设定抽取 |
| `chapter-summary` | 章节摘要 |

**安装与使用**
- 安装：支持 SkillHub 安装（Node 直连匿名接口）、zip 导入、文件夹导入。
- 适用类型：每个技能可以设置适用的检查类型（`appliesTo`）。创建任务时可以选择用内置技能，也可以选择某个已安装的技能。
- 读取内容：读取 SKILL.md 正文，以及 `references/` 下的 `.md`、`.txt` 文件，总长度上限 24000 字。`scripts/` 下的文件和其他文件都不读、不执行（INV-13）。

## 理由 (Rationale)
- 编辑器协议和技能规则分层，让第三方技能也能产出可定位、可一键修正的结构化问题。
- 内置检查也做成技能，代码路径只有一条，测试面更小，用户也可以照着内置技能写自己的技能。
- 自行实现安全解压和完整 YAML 解析，弥补官方 CLI 的不足。

## 后果 (Consequences)
- **正面**
  - 可以复用 SkillHub 生态。
  - 用户可以导入自定义规则，比如「本书禁用词」或「起点风格审稿标准」。
- **负面 / 代价**
  - 与本作品无关的技能内容也会占用上下文，需要设置长度上限。
  - SkillHub 接口变更时需要适配；该功能出错不影响编辑和本地导入。

## 实施补充（2026-10-09，T11）

不改变上述决定，只记录实施中确定的细节（完整约定见 ARCHITECTURE §7.5、INV-13）：
- **解压不用 `fflate`，改用自写中央目录解析 + `node:zlib`**：识别符号链接需要读 zip 的 external attributes，`fflate` 不提供；`fflate` 也只能按声明大小限额，声明造假的 zip 炸弹会撑爆内存。`inflateRawSync` 的 `maxOutputLength` 能在限额处硬性中止，再核对实际大小与 CRC。`fflate` 仍用于打包脚本解压 Node 官方发行包。
- **只保存 .md / .txt**：其余文件（脚本、图片）在安装时直接丢弃，不落盘。「不执行任何文件」因此不依赖调用方自觉。
- **SkillHub 技能名用 displayName**：SKILL.md 的 `name` 常是英文标识符，与作者在搜索结果中看到并选择的名字不一致；取详情失败时回退到 `name`。
- **内置技能加载期校验**：清单或 SKILL.md 不合法时程序启动失败，而不是在第一次检查时才暴露。
- **安全报告链接只接受 https**：界面会把 `reportUrl` 渲染成链接，防止 `javascript:` 等协议。
